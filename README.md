# درفش (Derafsh)

> یک اتصال. یک دکمه. درفش برافراشته.

درفش یک کلاینت VPN فارسی‌اول برای اندروید و iOS است — تجربه‌ی «یک دکمه اتصال» بدون تنظیمات و بدون import اشتراک. نام و هویت بصری آن از **درفش کاویانی**، درفش شاهی ایران باستان، گرفته شده است (پژوهش و توکن‌های طراحی: [`docs/DESIGN.md`](docs/DESIGN.md)).

## وضعیت — PART 1 (پوسته‌ی طراحی)

این کامیت، بخش ۱ از ۴ بخش پروژه است:

- ✅ هویت بصری کاویانی (رنگ، فرم، تایپوگرافی وزیرمتن) + انیمیشن‌ها
- ✅ صفحه‌ی تک‌صفحه‌ای: ستاره‌ی کاویانی زنده، دکمه‌ی اتصال، تایمر، نوار مصرف رایگان (۳۰ دقیقه/روز)
- ✅ لیست سورس‌ها با قفل پرمیوم + پی‌وال متقاعدکننده
- ✅ گیت به‌روزرسانی اجباری (`MandatoryUpdateGate` — در PART 3 از Worker تغذیه می‌شود)
- ✅ بخش پیشرفته‌ی مخفی (۵ بار لمس شماره‌ی نسخه) + صفحه‌ی «متن‌باز و لایسنس‌ها»
- ⬜ PART 2: موتور واقعی sing-box (libbox)
- ⬜ PART 3: Worker (Cloudflare) + فعال‌سازی کد تک‌دستگاهی
- ⬜ PART 4: بات تلگرام + پرداخت

موتور اتصال در این نسخه **استاب** است (تمام UI قابل تست است)؛ اتصال واقعی در PART 2 با libbox رسمی sing-box اضافه می‌شود.

## بیلد

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release                 # اندروید
flutter build ios --release --no-codesign   # iOS (IPA امضانشده — توزیع دستی)
```

بیلدهای CI با GitHub Actions در تب Actions ساخته می‌شوند (APK امضاشده + IPA امضانشده).
